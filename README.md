# EduGenie

EduGenie is a lightweight AI-powered educational assistant built with:

- FastAPI
- HTML
- CSS
- JavaScript
- OpenAI API

## Features

- Ask educational questions
- Generate quizzes
- Grade quizzes
- Generate learning paths
- Summarize educational text
- Personalized learning recommendations
- Responsive interface
- Demo mode
- Cloud AI support
